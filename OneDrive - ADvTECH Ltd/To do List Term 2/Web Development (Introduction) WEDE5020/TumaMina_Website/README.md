## Part 2 - CSS Styling and Responsive Design

### What Was Done in Part 2
- Created an external stylesheet `css/style.css` and linked it to all 5 HTML pages.
- Applied a CSS reset (`* { margin: 0; padding: 0; box-sizing: border-box; }`) for consistent styling across browsers.
- Set base typography using Google Fonts: **Poppins** for headings and **Open Sans** for body text (as per the Part 1 proposal).
- Used the approved colour palette:
  - Dark Blue `#1A2B4C` - Header, footer, headings
  - Teal `#2D9B8E` - Buttons, accents, hover states
  - Light Grey `#F5F7FA` - Page background
  - White `#FFFFFF` - Content cards
  - Dark Grey `#333333` - Body text
- Styled the header and navigation using **CSS Flexbox** for a clean, modern layout.
- Added `:hover` pseudo-classes to navigation links, buttons, and table rows for interactivity.
- Styled forms (enquiry + contact) with focus states and accessible labels.
- Used CSS Grid (`.steps`) for the "How It Works" section.

### Responsive Design
- Implemented two **media queries**:
  - `@media (max-width: 768px)` — Tablet
  - `@media (max-width: 480px)` — Mobile
- Used **relative units** (`rem`, `%`, `vw`) for font sizes and widths.
- Navigation, steps grid, buttons, and typography all adapt to smaller screens.
